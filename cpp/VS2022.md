## Visual Studio 2022でビルドする方法

このプロジェクトに含まれているVisual Studio用プロジェクト生成バッチは、Visual Studio 2019を前提としています。

Visual Studio 2022でビルドする場合は、CMakeのジェネレーター設定と、同梱されているOpenCVのVisual Studio判定処理を変更してください。

### 必要な環境

あらかじめ、次のソフトウェアをインストールしてください。

- Visual Studio 2022
    - `C++によるデスクトップ開発` ワークロード

- CMake

CMakeが使用できることは、PowerShellなどで次のコマンドを実行して確認できます。

```powershell
cmake --version
```

バージョン情報が表示されれば、CMakeを使用できます。

### Visual Studio 2022用にバッチファイルを変更する

`generate-vs-project.bat` では、Visual Studio 2019用のCMakeジェネレーターが指定されています。

Visual Studio 2019用の指定は次のとおりです。

```bat
call :cmakeParams "Visual Studio 16 2019" "x64"
```

Visual Studio 2022では、ジェネレーター名を次のように変更します。

```bat
call :cmakeParams "Visual Studio 17 2022" "x64"
```

x86版も生成する場合は、`Win32`を指定します。

```bat
call :cmakeParams "Visual Studio 17 2022" "Win32"
```

Visual Studio 2022用に変更した例は次のとおりです。

```bat
:buildALL
call :gen2022-x86
call :gen2022-x64
GOTO:EOF

:gen2022-x86
mkdir build-win-vs2022-x86
pushd build-win-vs2022-x86
call :cmakeParams "Visual Studio 17 2022" "Win32"
popd
GOTO:EOF

:gen2022-x64
mkdir build-win-vs2022-x64
pushd build-win-vs2022-x64
call :cmakeParams "Visual Studio 17 2022" "x64"
popd
GOTO:EOF

:cmakeParams
echo cmake -G "%~1" -A "%~2" -DOCR_OUTPUT=%BUILD_OUTPUT% -DOCR_BUILD_CRT=%MT_ENABLED% -DOCR_ONNX=%ONNX_TYPE% ..
cmake -G "%~1" -A "%~2" -DOCR_OUTPUT=%BUILD_OUTPUT% -DOCR_BUILD_CRT=%MT_ENABLED% -DOCR_ONNX=%ONNX_TYPE% ..
GOTO:EOF
```

呼び出し側のラベル名も、Visual Studio 2022用に変更します。

```bat
set flag=2

if %flag% == 0 (
    call :buildALL
)^
else if %flag% == 1 (
    call :gen2022-x86
)^
else if %flag% == 2 (
    call :gen2022-x64
)^
else (
    echo "入力エラー！Input Error!"
)
```

### OpenCVのVisual Studio判定を修正する

同梱されているOpenCVには、Visual Studio 2019用の`vc16`ライブラリが含まれています。

```text
opencv-static/windows-x64/x64/vc16
```

Visual Studio 2022では、通常は`vc17`が選択されます。ただし、Visual Studio 2022の新しいMSVCでは、`MSVC_VERSION`が`1940`以降になることがあります。

古い`OpenCVConfig.cmake`では、Visual Studio 2022の判定が次のようになっています。

```cmake
elseif(MSVC_VERSION MATCHES "^193[0-9]$")
```

この条件は`1930`から`1939`までにしか一致しません。

`MSVC_VERSION`が`1940`以降の場合はVisual Studioのランタイムを判定できず、次のような警告が表示されます。

```text
OpenCV RUNTIME:

Found OpenCV Windows Pack but it has no binaries compatible with your configuration.
```

Visual Studio 2022の`193x`と`194x`の両方に対応するため、次のファイルを開きます。

```text
opencv-static/windows-x64/OpenCVConfig.cmake
```

Visual Studio 2022の判定条件を、次のように変更します。

変更前：

```cmake
elseif(MSVC_VERSION MATCHES "^193[0-9]$")
```

変更後：

```cmake
elseif(MSVC_VERSION MATCHES "^19[34][0-9]$")
```

該当部分の修正例は次のとおりです。

```cmake
elseif(MSVC_VERSION MATCHES "^19[34][0-9]$")
  set(OpenCV_RUNTIME vc17)
  check_one_config(has_VS2022)

  if(NOT has_VS2022)
    set(OpenCV_RUNTIME vc16)
    check_one_config(has_VS2019)

    if(NOT has_VS2019)
      set(OpenCV_RUNTIME vc15)
      check_one_config(has_VS2017)

      if(NOT has_VS2017)
        set(OpenCV_RUNTIME vc14)
      endif()
    endif()
  endif()
endif()
```

この変更により、次の順序でOpenCVのライブラリが検索されます。

1. Visual Studio 2022用の`vc17`
2. `vc17`が存在しない場合はVisual Studio 2019用の`vc16`
3. `vc16`も存在しない場合は、それ以前のライブラリ

このプロジェクトには`vc16`のみが含まれているため、最終的に`vc16`が選択されます。

正常に認識された場合は、CMake実行時に次のように表示されます。

```text
OpenCV ARCH: x64
OpenCV RUNTIME: vc16
OpenCV STATIC: ON
```
